01

Visão Geral da Oferta

The King’s Code é uma oferta digital no nicho de manifestação, mindset, identidade e desenvolvimento pessoal, construída em torno de um conceito central:

Michael Jackson teria utilizado, durante anos, um protocolo específico de reprogramação de identidade que contribuiu para transformar a visão que ele tinha de si mesmo e, consequentemente, seus resultados.

A oferta apresenta esse protocolo como um sistema de 4 fases, transformado em uma aplicação mobile personalizada com auxílio de IA.

O posicionamento principal é:

Não é apenas manifestação. Não é apenas afirmação. Não é apenas visualização. É um protocolo completo de reprogramação de identidade.

02

Big Idea

A grande ideia da oferta é que:

Michael Jackson não simplesmente “acreditava que seria famoso”. Ele teria desenvolvido e executado diariamente um método específico para programar a própria identidade antes de conquistar os resultados pelos quais ficou conhecido.

A VSL conecta essa narrativa a anotações, afirmações e práticas atribuídas a Michael Jackson durante o período anterior ao auge da carreira.

O principal elemento visual utilizado é o famoso conceito de escrever metas e afirmações no espelho.

A promessa narrativa é que aquilo que o público conhece como:

  • manifestação;
  • visualização;
  • afirmações;
  • scripting;
  • vision boards;

seriam apenas fragmentos incompletos de um sistema maior.

Esse sistema completo recebe o nome de:

Jackson’s Method / The King’s Code

04

Mecanismo Único

O mecanismo da oferta é baseado na ideia de Identity Reprogramming.

Segundo a narrativa da VSL, a maioria das técnicas de manifestação falha porque tenta alterar resultados sem primeiro alterar a identidade processada pelo cérebro.

O The King’s Code apresenta quatro etapas.

Fase 1 — RESET

Objetivo:

Levar o usuário de um estado mental mais acelerado para um estado mais receptivo.

A VSL associa essa etapa a frequências cerebrais e ao estado theta.

Duração apresentada:

aproximadamente 3 minutos.

Fase 2 — SYNTAX

O usuário recebe comandos/afirmações personalizados.

A diferença apresentada é que não são afirmações genéricas como:

“I am wealthy.”

O sistema utilizaria uma estrutura linguística específica baseada em:

  • presente;
  • identidade;
  • comandos;
  • elementos sensoriais;
  • objetivo pessoal do usuário.

Duração:

aproximadamente 5 minutos.

Fase 3 — MIRROR

O usuário executa uma prática diante do espelho mantendo contato visual com o próprio reflexo enquanto repete a programação daquele dia.

O conceito principal é:

associar visualmente a nova identidade ao próprio “eu”.

Duração:

aproximadamente 5 minutos.

Esse é provavelmente o componente mais visual e mais forte para ads.

Fase 4 — ANCHOR

Realizada antes de dormir.

A proposta é consolidar a programação realizada durante o dia.

A VSL posiciona essa etapa como o componente que estaria ausente na maioria dos métodos tradicionais de manifestação.

Duração:

aproximadamente 3 minutos.

Como editar a página
THE KING'S CODE — PÁGINA DE VSL (ENTREGA PARA AFILIADO)
========================================================

O QUE TEM AQUI
--------------
  index.html ..... a página completa (HTML único, CSS e JS embutidos)
  garantia.png ... selo de garantia (deixe na MESMA pasta do index.html)

COMO SUBIR
----------
Suba os 2 arquivos juntos, na mesma pasta, em qualquer hospedagem
(servidor próprio, Vercel, Netlify, cPanel etc.). Não precisa de PHP
nem banco de dados — é 100% estático.

O QUE VOCÊ PRECISA EDITAR (3 coisas)
------------------------------------
Abra o index.html em qualquer editor de texto. Os 3 pontos estão
marcados com comentários grandes — é só procurar pelo texto:

1) LINK DE COMPRA
   Procure por:  SEU_LINK_DE_COMPRA_AQUI
   Aparece 3 vezes (os 3 botões da página). Use localizar/substituir
   e troque pelo seu link de checkout/camuflado.

2) EMBED DA VSL
   Procure por:  [TROCAR AQUI: EMBED DA VSL]
   São 2 blocos:
     - Bloco 1 (no <head>): linhas de preload do player atual.
       Troque pelas do seu player ou apague (é só otimização).
     - Bloco 2 (no corpo): o player em si. Apague o
       <vturb-smartplayer> + <script> e cole o embed do SEU vídeo.
   ATENÇÃO: a revelação do pitch e o botão usam a tag
   <vturb-smartplayer>, então o novo embed precisa ser VTurb.

3) TEMPO DO PITCH
   Procure por:  [TROCAR AQUI: TEMPO DO PITCH]
   Edite a variável delaySeconds (em segundos de vídeo ASSISTIDO).
   Ex.: pitch aos 20min30s -> delaySeconds = 1230
   O conteúdo abaixo do vídeo (botão, preço, oferta) só aparece
   quando o lead assiste até esse ponto. Se pausar, o contador para.

PIXEL / RASTREAMENTO
--------------------
A página foi entregue SEM nenhum pixel ou rastreador. No <head> há um
comentário "SEU PIXEL / RASTREAMENTO AQUI" — cole ali o seu Meta
Pixel, UTMify, RedTrack etc.

COMO FUNCIONA A PÁGINA (resumo)
-------------------------------
- Tudo abaixo do vídeo começa oculto (classe .hide no <main>).
- O player VTurb revela o conteúdo no tempo configurado (persiste
  entre visitas do mesmo navegador).
- Quando o conteúdo é revelado, começa o timer de 15:00 (persiste
  via localStorage) e a barra de "vagas" sobe sozinha até 70/72.
