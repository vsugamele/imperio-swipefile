All Types

Static

Static/Sticky Navbar
A simple navigation bar that is usually fixed to the top and doesn't contain any dropdowns.

Dropdown

Dropdown/Flyout Menu
The dropdown flyout allows for additional menu items to be nested within parent items.

Mega Menu

Mega Menu
A mega menu is a large dropdown that displays multiple navigation links and categories in an organized layout.
Find out more

Side Bar

Side Bar Menu
A sidebar is a vertical panel used to display navigation links, filters, or additional content alongside the main page.
Find out more

Search Bar

Search Bar
A search bar is an input field where users can type keywords or phrases to search for specific information or content.

Announcement

Announcement Bar
An announcement bar is a slim banner in a website's navigation, highlighting key messages like promotions or updates.

Full Screen

Full Screen Menu
Full screen menus cover the entire page and often have graphic elements.

Breadcrumbs

Breadcrumbs
A secondary navigation that helps users trace their location.

About

Navbar Gallery is a curated navigation-focused design inspiration website.

Navbar Gallery began with a spark of inspiration on Twitter, ignited by the creation of footer.design.   

Surprisingly, I discovered that there is no dedicated navigation-focused resource for designers. Recognizing this need in the design world, I embarked on a mission to fill it, building Navbar Gallery in public on Twitter.

Made by Christina Liubynska
